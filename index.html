Save tips to GitHub

Saving commits tips.json to . To do that the page needs a fine-grained GitHub token. It's kept in this browser on this device only.

  1. Open GitHub → new fine-grained token (Settings → Developer settings → Personal access tokens → Fine-grained tokens).
  2. Name it something like Driving tips map and pick an expiry. You'll make a new one when it runs out.
  3. Repository access: “Only select repositories” → .
  4. Permissions: Repository permissions → Contents: Read and write. Nothing else. (GitHub adds Metadata: read-only by itself.)
  5. Generate it, copy it (it starts github_pat_) and paste it below.

Without a token the map still works. Saving then keeps changes on this device and copies them as JSON, so you can paste them to Claude to commit. Anyone using this browser profile can use a saved token, so don't save it on a shared computer.
